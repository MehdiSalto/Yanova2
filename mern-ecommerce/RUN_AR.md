# تشغيل YANOVA — النسخة المصلحة 1.1.0

هاد النسخة فيها السورس ديال المتجر، لوحة الإدارة والـBackend كاملين.
الشراء كيدوز عبر رابط خارجي ديال البائع. ما كاينش دابا Checkout، أداء
إلكتروني أو تدبير الطلبات.

## التشغيل فالحاسوب

خصك Node.js إصدار 20.19 أو أكثر، وMongoDB خدام محلياً أو عن بعد.
حل Terminal وسط المجلد `mern-ecommerce` وشغّل:

```sh
npm run install:all
npm run setup
```

من بعد حل `backend/.env`:

- عدّل `MONGO_URI` برابط قاعدة البيانات ديالك.
- عدّل `DEFAULT_ADMIN_EMAIL` بالإيميل ديالك.
- كلمة السر الأولية كتلقاها فـ`DEFAULT_ADMIN_PASSWORD`؛ تولّدات بشكل عشوائي.
- خَلّي `JWT_ACCESS_SECRET` سري وما تشاركو حتى مع شي حد.

السكريبت ما كيبيّن حتى سر فالـTerminal، وما كيبدلش كلمة سر حساب موجود
من قبل فقاعدة البيانات. إلا عندك حساب قديم، دخل بيه وبدّل كلمة السر
من Settings → Change password.

شغّل MongoDB، ومن بعد:

```sh
npm run dev
```

| الجزء | الرابط |
| --- | --- |
| المتجر | http://localhost:3000 |
| لوحة الإدارة | http://localhost:5174/admin/login |
| الـAPI | http://localhost:5000/api |

الدخول كيبقى خدام حتى تسالي مدة الجلسة، ومن بعد كترجع تسجّل الدخول.
ما كاينش تجديد تلقائي للجلسة فهاد النسخة.

## أول تجربة عملية

1. دخل للإدارة وزِد منتج، الثمن، الصورة ورابط الشراء الخارجي.
2. خليه Draft وتأكد ما كيبانش للزوار؛ من بعد نشره بـPublished.
3. جرّب Offers وBanners؛ العرض اللي ما بداش أو سالات المدة ديالو ما كيبانش للزوار.
4. عدّل اسم المتجر، About والسياسات من Settings، وعاود حل الصفحة باش تشوف التغيير.
5. صيفط رسالة من Contact وشوفها فالإدارة. Read وReplied غير حالات تنظيمية وما كيصيفطوش إيميل.

## البناء والاستضافة

```sh
npm run build
```

هاد الأمر كيبني المتجر ولوحة الإدارة بجوج. فالاستضافة، ضبط `backend/.env`
على `NODE_ENV=production`، `COOKIE_SECURE=true` و`CLIENT_URLS` بالدومين
الصحيح، وخدم عبر HTTPS. من بعد شغّل `npm start`؛ الإدارة كتكون فـ`/admin/`.

خص الاستضافة تدعم Node وWebSocket. الصور خاصها `UPLOAD_DIR` فمساحة
دائمة باش ما تضيعش مع إعادة النشر. إعدادات الـProxy، قاعدة البيانات والنسخ
الاحتياطي خاصها تتجرب على الاستضافة اللي غادي تختار.

## شنو تصلّح وشنو باقي

التغييرات المفصلة فـ`IMPLEMENTATION.md`، وخريطة الملفات والـAPI فـ`README.md`.
اختبارات الـBackend كتخدم بـ`npm test`، وبناء الواجهتين بـ`npm run build`.
الاختبارات المحلية ما كتستعملش معلومات الدخول ولا قاعدة البيانات الحقيقية ديالك.

باقين تنبيهات فبعض أدوات البناء والتطوير القديمة، ومفصلين فالتقرير. هاد الأدوات
خاصها ترقية منفصلة؛ فالاستضافة استعمل النسخة المبنية وما تعرّضش سيرفر التطوير.

الربط الحقيقي مع MongoDB، النشر فاستضافتك، المحتوى التجاري النهائي، الدومين
والـSEO المفصل باقين خاصهم التحقق. الطلبات والأداء داخل المتجر خاصية جديدة
خاصها تصميم وتطوير بوحدها.

الملفات السرية وGit القديم ما مرفقينش. أي كلمات سر كانت مكشوفة فالنسخة
القديمة خاصها تتبدل فالخدمات الأصلية ديالها؛ حذفها من النسخة الجديدة بوحدو
ما كيلغيهاش.
